01为什么这个报错只在 Docker 里出现？

对
你的答案

容器没 host 网络，连不上宿主机 MySQL，要改 network 或者 IP。

标准答案

容器默认独立网络命名空间，127.0.0.1 指向容器自身。需 --network host 或改用宿主机内网 IP。

02git rebase 到底做了什么，和 merge 的区别在哪？

部分对
你的答案

把当前分支的提交重新放到目标分支后面，历史更直。merge 会多一个合并提交。

标准答案

rebase 逐个重放提交并生成新 commit hash，历史线性但改写历史，已推送的分支要慎用。merge 保留分叉，产生 merge commit，不改写历史。

03policy 在代码语境里通常指什么？

对
你的答案

一套约束规则，比如重试策略、权限策略。

标准答案

预定义的约束或规则集，如 retry policy、IAM policy，通常声明式配置而非硬编码。

04容器里连不上宿主机 MySQL，怎么改最稳？

错
你的答案

把 127.0.0.1 改成 localhost 就行。

标准答案

localhost 在容器内仍指向容器自身，改了没用。要用宿主机内网 IP、--network host，或 host.docker.internal（Linux 需额外映射）。
